# HRM Plugin - WordPress Human Resource Management System

A custom WordPress plugin built for managing basic Human Resource Management (HRM) operations such as employee records, attendance tracking, and role-based management within the WordPress dashboard.

This plugin demonstrates WordPress plugin development, custom admin menus, database handling, and backend logic integration.

---

##  Features

- Employee Management (Add / Edit / Delete)
- Attendance Tracking System
- Role-based Access (Admin/HR roles)
- Custom WordPress Admin Menu
- Custom Database Tables for HR data
- Secure form handling using WordPress standards
- Lightweight and easy to extend

---

##  Tech Stack

- WordPress
- PHP
- MySQL
- WordPress Hooks & Filters
- WP Admin Panel
- HTML / CSS / JavaScript
